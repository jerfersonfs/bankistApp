Esse é um projeto no qual é um material didático de um curso que eu faço na Udemy, o curso do professor Jonas Schmedtmann. Nele estou aprendendo a desenvolver um sistema bancário simples utilizando o JavaScript.  
O que estou aprendendo com o desenvolvimento desse material:  
-> Call stack  
-> Função e escopo  
-> Closures  
-> Métodos como: reduce, forEach, filter, map, find, etc.  
Com este projeto, estou conseguindo compreender melhor como métodos de array podem substituir loops tradicionais, tornando o código mais declarativo e legível, além de entender como o JavaScript gerencia a pilha de execução durante chamadas de função encadeadas.
